Arrows / asterisks as bullet markers

Bullet is always •, applied via CSS ::before. → stays inside the bullet's prose for state changes (380 ms → 18 ms).

no

Adjectives without numbers

"Designed scalable, high-performance, world-class sharding for a massive timeseries workload using cutting-edge approaches."

Zero verifiable signal. Replace every adjective with a number, a decision, or a trade-off — or cut the bullet.
