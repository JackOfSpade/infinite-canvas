# Practice-interview reading script (SYNTHETIC)

This is a made-up interview answer. It contains no real person, employer or project.
It exists only to measure whether Apple's on-device SpeechTranscriber keeps spoken
hesitation fillers and restarts.

How to read it (about 2.5 minutes):

- Read naturally, at a conversational pace, as if answering an interviewer out loud.
- Say EVERY marked filler. `{um}` means say "um". `{uh}` means say "uh". Do not skip any.
- `[restart: some words]` means say those words out loud, break off as if you changed your
  mind, then carry on with the words that follow. Do not skip the abandoned words.
- Do not say the braces, brackets or the word "restart".
- Only the text between the START and END markers below is scored.
